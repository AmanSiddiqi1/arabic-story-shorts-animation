## Series changes (for ALI-03, which copies `ab_kit.js`, `ab_cast.js`, `ab_sets.js` and parts of `a2_base.js`)
- `ab_kit.js`, `ab_cast.js`, `ab_sets.js`: **no changes.**
- `a2_base.js`, `abSay(...)`: the balloon is clamped inside the panel. Replace its `const r = S.label(...)` line by:
  `let size = o.size || 52, w = a2LabelW(S, txt, size); const room = 1000 - 2 * A2_MARGIN - (o.icon ? 70 : 0); if (w > room) { size *= room / w; w = room; }`
  `const lo = A2_MARGIN + w / 2 + (o.icon ? 70 : 0), hi = 1000 - A2_MARGIN - w / 2; ctx.translate(K.clamp(x, lo, hi) - x, 0); if (to) to = [to[0] - (K.clamp(x, lo, hi) - x), to[1]];`
  `const r = S.label(ctx, txt, x, y + wb, K.clamp((t - steps[0][0]) / 0.3), { size, balloon: !o.tag, to: o.tag ? null : to, color: o.col });`
  and the icon line uses `size` instead of `(o.size || 52)`.
- `a2_base.js`, new before `a2Tag`: `const A2_MARGIN = 34;` and
  `function a2LabelW(S, text, size)` (measures the style label on a cached offscreen 1080 x 1920 canvas, `K.cached('a2lw:'...)`).
- `a2_base.js`, `a2Tag(...)`: first statement after the time test clamps x: `{ const w = a2LabelW(S, text, o.size || 46) * 1.15; x = K.clamp(x, A2_MARGIN + w / 2, 1000 - A2_MARGIN - w / 2); }`.
- `a2_base.js`, `a2CaveWorld(..., o)`: new option `o.cool` 0..1 (cold repaint of the set: multiply `#6a78c8` at 0.78, screen `#9aa8e8`
  at 0.14, a gold rim glow on the mound; the gold glows are reduced by 0.6 * cool). The chest's glow is now drawn after `abCaveLive`
  (draw order only). Without `cool` the cave draws as before.
- `a2_base.js`, new at the end: `a2BackCel(ctx, P, pal, o, k)` (back-of-head cover cel), `a2DuskTown()` and
  `a2SunsetTown(ctx, t, x, base, s)` (the village repainted for sunset, lit windows).
- `stills.mjs`: page load timeout raised to 180 s (the shared machine was overloaded); harmless for other stories.
